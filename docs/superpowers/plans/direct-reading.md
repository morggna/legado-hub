# 单入口多用户阅读

用户确认的流程：账号密码登录，邀请码注册 → 搜索全部启用书源 → 加入个人书库 → 默认按章阅读；整本下载是可选操作，支持暂停、继续和 TXT 导出。

实现边界：复用 LegadoHub 的认证、插件调度和存储基础；阅读器移植 legado-server 的界面与交互。管理员管理账号、邀请码和共享插件。用户书库、进度、下载隔离。前端衍生代码按 GPL-3.0 分发，保留 Hub 原 MIT 声明。

部署：干净安装在 SG-Oracle，唯一宿主监听 127.0.0.1:8765。用户自行反代；允许 read.uclau.de。不导入旧服务数据。

发布前：完整 verify.ps1；独立容器真实书源检索、入库、按需正文、整本下载、暂停继续、账号隔离和重启持久化；发布后检查端口、健康状态和登录接口。

未实现：用户私有 Legado JSON 执行引擎。不能将管理员共享插件描述为私人书源。
